# 공룡 수학 탐험대

지적장애가 있는 어린이를 위해 만든 태블릿용 한국어 수학 학습 게임입니다.
브라키오(청록색 브라키오사우루스), 스테고(주황 골판의 초록 스테고사우루스),
티라노(주황색 티라노사우루스)와 함께 세 곳의 탐험지를 여행합니다.

- 별도 빌드 과정이 없는 HTML/CSS/JavaScript 앱입니다. 숨겨진 러너 게임은 Canvas로 그립니다.
- 그림(SVG/Canvas), 음악(코드로 작곡해 Web Audio로 합성), 효과음은 모두 이 저장소의 코드로 직접 만든 창작물입니다.
- 글꼴은 Google Fonts의 Jua, Black Han Sans(SIL Open Font License)를 쓰며, 인터넷에 연결되지 않으면 기기의 한글 글꼴로 대신 표시됩니다.

## 실행 방법

```bash
npm start            # = python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 열기
```

`index.html`을 정적 파일 서버로 열면 됩니다.

서버 없이 태블릿에서 바로 열고 싶다면 `npm run build`로 만든 **`dist/dino-math.html`** 파일 하나만
기기로 옮겨 브라우저에서 열면 됩니다(그림·소리·코드가 모두 이 파일 안에 들어 있습니다). 태블릿에서는 같은 네트워크에서 `http://<컴퓨터 IP>:8080`으로 접속합니다.

## 학습 구성

| 스테이지 | 환경 | 수호 공룡 | 내용 |
|---|---|---|---|
| 1스테이지 | 울창한 숲 | 브라키오 | 연산 기호 끌어다 놓기, 16단계 |
| 2스테이지 | 바위 협곡 | 스테고 | 계산기로 계산하기, 30단계 (자릿수별 기본 18단계 + 두 연산자 식 12단계) |
| 3스테이지 | 용암 화산 | 티라노 | 생활 속 이야기 문제, 30단계 (앞 15단계는 덧셈·뺄셈 중심, 뒤 15단계는 곱셈·나눗셈) |

- 모든 단계는 **정답 3개**를 맞히면 클리어됩니다. 오답과 건너뛴 문제는 세지 않고, 같은 문제는 한 번만 셉니다.
- 시간 제한이 없습니다. 끌어다 놓기가 어렵다면 **눌러서 고르고 → 칸을 누르는** 방식으로도 할 수 있습니다.
- 두 연산자 식은 일반적인 계산 순서(곱셈·나눗셈 먼저)를 따르며, 나눗셈은 항상 나누어떨어지고 답은 0 이상의 정수입니다.
- 3스테이지에서는 계산식을 보여 주지 않으며, 힌트도 식을 알려 주지 않습니다.

## 주요 조작

- **계산기**: `=`를 누르면 숫자 카드가 컨베이어에 생깁니다. `=`를 다시 눌러도 계산이 반복되거나 카드가 더 생기지 않습니다. 계산이 끝나면 `AC`가 빨갛게 깜빡이고, `AC`를 한 번 누르면 멈춥니다.
- **숫자 카드**: 정답 칸 가까이에 놓으면 쏙 들어가고, 다시 끌어내거나 다른 카드로 바꿀 수 있습니다.
- **아기 공룡**: 카드를 집으면 입을 벌립니다. **입 가까이**에 놓아야만 냠냠 먹어서 카드를 없앱니다(둥지나 몸통에 놓으면 지워지지 않습니다).
- **메뉴**(오른쪽 위): 이어하기, 표지로, 스테이지 선택, 현재 스테이지 지도, 문제 건너뛰기, 단계 바로 고르기, 계산기, 힌트·설명 글·효과음·배경 음악 켜고 끄기, 클리어 기록 초기화.

## 비밀 게임

메뉴의 **계산기**에서 숫자 `2243003`을 직접 누르고 `=`를 누르면 계산기가 깨지면서
숨겨진 게임 **「스피노의 대탈출」**이 시작됩니다. (계산 결과가 2243003이 되는 것으로는 열리지 않습니다.)
화면을 누르거나 스페이스·위쪽 화살표 키를 누르면 점프합니다.

## 코드 구조

```
index.html              화면 골격
css/style.css           디자인(가로·세로 태블릿 대응, 동작 줄이기 설정 존중)
js/math/generator.js    문제 생성, 계산 순서 평가, 1·2스테이지 단계 정의
js/math/stories.js      3스테이지 이야기 문제(단계마다 2가지 이상)
js/math/progress.js     정답 3개 클리어 규칙
js/ui/boards.js         기호 칸·숫자 카드·아기 공룡 입 판정 모델
js/ui/art.js            공룡·환경·지도 그림(SVG)
js/ui/drag.js           터치·마우스 끌어다 놓기
js/calc/calc-engine.js  계산기 엔진(= 반복 방지, 비밀 번호 판정)
js/calc/calc-ui.js      계산기 화면
js/core/storage.js      설정·클리어 기록 저장(옛 형식 이전 및 재등장 방지)
js/core/music.js        배경 음악 작곡 데이터
js/core/audio.js        음악 재생기·효과음·오디오 잠금 해제/복구
js/runner/runner-logic.js  러너 물리·장애물·난이도(상한 없음)
js/runner/runner.js     러너 그림·입력·일시 정지
js/app/play.js          문제 풀이 화면
js/app/app.js           화면 전환·메뉴·설정
```

## 테스트

```bash
npm test             # 단위 테스트 (Node 내장 node:test)
npm start &          # 정적 서버를 켠 뒤
npm run test:e2e     # Playwright + Chromium 실제 브라우저 테스트
```

단위 테스트는 문제 생성과 계산 순서, 정답 3개 규칙, 계산기 `=` 반복, 카드 이동·교체의 중복 방지,
입 영역 판정, 기록 초기화 유지, 비밀 번호 판정, 점프 물리와 충돌, 1~4개 장애물 묶음,
속도·생성 간격의 무제한 변화, 음악 전환과 재생 속도 검증을 다룹니다.
브라우저 테스트는 실제 끌어다 놓기, 오디오 잠금 해제, 메뉴, 러너 일시 정지, 그리고
10가지 태블릿 크기(세로·가로)에서 화면이 겹치거나 잘리지 않는지 확인합니다.
